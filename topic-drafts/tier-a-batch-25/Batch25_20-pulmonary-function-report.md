## Synopsis (gist)

The stored text is the 2017 ATS technical statement on a standardized pulmonary function report. Directive sentences about report content, including diffusing capacity where the sentence states it, are listed. It is a reporting statement, not a stand-alone DLCO interpretation protocol.
