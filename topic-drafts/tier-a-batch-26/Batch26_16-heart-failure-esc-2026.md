# enalapril ACE inhibitor survival reduced left ventricular ejection fraction: evidence record (batch 26, not published)

**Lead guideline:** 2026 ESC Guidelines for the management of heart failure. (2026), PMID 42661420, document id 2719. Read in full from the stored text.

## Synopsis (gist)

The spreadsheet lead is a post-hoc analysis of PARADIGM-HF comparing lower-than-target doses of sacubitril/valsartan and enalapril. That stored text has no should, must, or recommend sentence. This file uses the 2026 ESC guideline for the management of heart failure. Rows that survived from the recommendation tables are listed with the class and level printed next to them in the stored text, including prevention statements such as a systolic blood-pressure target under 130 mmHg and SGLT2 inhibitor recommendations in specified diabetic populations. Enalapril is named in the stored text; a dose or survival claim is listed only where a table row states it.
